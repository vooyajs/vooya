# Examples

Examples are small, inspectable demonstrations of the integration boundary.
They are not component-library products and should not be treated as generic
benchmarks unless a benchmark page says so.

## Available examples

- [Scatter plot](../guide/scatter-plot.md): a Rust-owned Canvas surface with a
  Vue host and a large point set.
- [Data-grid benchmark](../benchmarks/data-grid.md): the workload definition and
  measurement rules for the grid case.
- [Trace waterfall](../benchmarks/trace-waterfall.md): an exploratory candidate
  for a later workload.

The repository also contains Vue, React, TaskList, DataGrid, and store fixtures.
Those fixtures are maintained primarily as integration evidence; the public
documentation will only promote an example when its setup and support boundary
are clear.
